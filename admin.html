⚙️ Hubungkan Panel ke GitHub (cukup sekali)

Setelah langkah ini selesai satu kali, tombol "🚀 Terbitkan ke Website" di tab Produk dan Agenda akan langsung menyimpan perubahan ke situs — siapa pun yang input data (termasuk orang awam) tidak perlu lagi membuka GitHub, mengunduh file, atau mengunggah manual.

  1. Buka github.com/settings/personal-access-tokens/new (perlu login akun GitHub pemilik repo afzazahra88-tech).
  2. Isi nama bebas, misal "Panel Admin MJA Berlian".
  3. Pada Repository access, pilih Only select repositories → pilih repo mja-berlian-web saja (jangan pilih semua repo).
  4. Pada Permissions → Repository permissions, cari Contents → ubah ke Read and write. Permission lain biarkan default (No access).
  5. Klik Generate token di bagian bawah, lalu salin kode token yang muncul (kode ini hanya tampil sekali).
  6. Tempelkan token tersebut ke kolom di bawah ini, lalu klik Simpan Pengaturan.
Penting soal keamanan: token ini hanya tersimpan di browser perangkat ini (tidak dikirim ke siapa pun selain GitHub). Jangan bagikan token atau tautan halaman admin ini ke sembarang orang, dan jangan pernah pilih "All repositories" saat membuat token — cukup pilih repo mja-berlian-web saja supaya kalaupun bocor, dampaknya terbatas.

Cara manual (dipakai hanya kalau tombol "🚀 Terbitkan ke Website" tidak bisa dipakai)

Kalau panel sudah tersambung lewat tab ⚙️ Pengaturan, langkah-langkah di bawah ini tidak perlu dilakukan lagi.

  1. Buka repository GitHub situs ini di github.com/afzazahra88-tech/mja-berlian-web.
  2. Masuk ke folder js.
  3. Klik file produk-data.js (atau agenda-data.js) yang lama, lalu klik ikon pensil (Edit) di kanan atas, atau hapus dulu lalu gunakan tombol Add file → Upload files di halaman folder js dan seret file baru hasil unduhan ke sana — GitHub otomatis menawarkan untuk menimpa file lama karena namanya sama.
  4. Setelah file terunggah, klik tombol hijau Commit changes di bagian bawah halaman.
  5. Untuk produk baru, jangan lupa juga unggah file foto-nya ke folder images/produk/<sub kategori>/ (misalnya images/produk/cincin/) dengan nama file yang sama persis dengan yang ditulis di formulir.
  6. Tunggu 1–2 menit, lalu refresh halaman produk.html atau berita-acara.html di situs — data baru akan langsung muncul.

Tidak perlu menulis kode apapun secara manual — file yang diunduh dari panel ini sudah dalam format yang tepat dan siap pakai.
